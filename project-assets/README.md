# Project Assets

Buat satu folder untuk setiap project di dalam folder ini:

```text
project-assets/
├── proj1-daihatsu/
├── proj2-house-of-goodness/
├── proj3-dunia-tanpa-syarat/
├── proj4-petualangan-paddle-pop/
├── proj5-freeport-3d-edirectory/
├── proj6-bca-solitaire/
├── proj7-iquartz-organic-growth/
├── proj8-engagement-campaign-surge/
└── proj9-integrated-campaign-bca/
```

Gunakan nama file yang konsisten:

```text
thumbnail.jpg
gallery-01.jpg
gallery-02.jpg
gallery-03.jpg
```

Thumbnail sebaiknya berasio 16:9. Gambar gallery boleh memakai ratio berbeda jika memang diperlukan untuk dokumentasi project.
